# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

1. **Beginner Crocheter:** Someone new to crochet who wants easy patterns, clear material lists, and a simple way to track what they are making.
2. **Experienced Crocheter:** Someone with years of crochet skill who manages multiple projects, wants to browse by interest, and wants to share their own work.
3. **Pattern Curator:** An admin who keeps the pattern library accurate, organized, and in a clean default state.

## Draft User Stories

1. As a beginner crocheter, I want to filter patterns by difficulty, so that I can find something I can realistically finish.
2. As a beginner crocheter, I want to see exactly which yarn and hook a pattern needs, so that I can shop for supplies before I start.
3. As a beginner crocheter, I want to open a pattern's detail page, so that I can read its full description before committing to it.
4. As a beginner crocheter, I want to start a project from a pattern, so that I can track my progress from the first stitch.
5. As a beginner crocheter, I want to update a project's status to Not Started, In Progress, or Finished, so that I can see at a glance what I'm working on.
6. As an experienced crocheter, I want to sort patterns by category, so that I can browse by what interests me, like amigurumi or wearables.
7. As an experienced crocheter, I want to edit my project notes, so that I can record changes I made to the pattern.
8. As an experienced crocheter, I want to delete a project I abandoned, so that my project list stays tidy.
9. As an experienced crocheter, I want to add a new pattern to the library, so that I can share my own designs with others.
10. As an experienced crocheter, I want to filter patterns by yarn weight, so that I can use up the yarn I already have.
11. As a pattern curator, I want to edit a pattern's materials and quantities, so that the information stays accurate.
12. As a pattern curator, I want to reset the database to its default state, so that I can restore the original patterns and sample data after testing.
